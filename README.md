# 随身终端 · 无职转生（mushoku-phone）

SillyTavern 酒馆助手前端：悬浮球 + 手机界面，含角色传讯（独立AI回复）、群聊路由、人物关系、CG相册、背包/手记/课题、世界书浏览编辑、记忆自动沉淀、数据迁移与多API方案管理。

> 无职转生角色卡的专属组件，架构参考 `qmsdaa/tavern_helper_template`（Counterfeit手机上游）与 `h675786161-prog/world-backstage` 社交终端。

## 安装

### 方式A · 卡内装载器（推荐，自动更新）

把角色卡中「随身终端-无职」脚本的内容替换为一行：

```js
import 'https://testingcf.jsdelivr.net/gh/ansdojaods/mushoku-phone@main/dist/mushoku-phone.js';
```

之后每次 `git push` 新版本，卡片无需重新导入即可更新（jsDelivr有缓存，分钟级生效；求即时可改用 `@main` 改为具体提交哈希）。

### 方式B · 直接粘贴（离线可用）

复制 `dist/mushoku-phone.js` 全文，在酒馆助手脚本库或卡片脚本中粘贴。更新需手动替换。

### 首次配置

发布版**不含API密钥**（公开仓库安全）。首次使用：

1. 打开终端 → 设置（齿轮）→ 接口密钥 → 粘贴你的密钥 → 保存
2. 也可存为多个「API方案」，下拉随时切换

## 数据接口（手机维护的世界书）

运行时自动创建并绑定卡片：**《无职转生-专属记忆》**

| 条目 | 内容 |
|---|---|
| 洛琪希/希露菲/艾莉丝专属记忆 | AI按记忆写入规范沉淀的角色记忆 |
| 想做的100件事 / 家人留下的课题 | 清单正文（按章节解锁） |
| 日记与课题记录 | 完成记录 |

主提示词侧需配合 `docs/随身终端上下文-世界书条目.md` 的上下文条目（无职卡已内置）。
