# 随身终端 · 配套世界书条目

与 `随身终端-无职.js` 配套使用。卡片注入已完成，本文件是组件副本，供其他卡复用。

## 条目 1：EJS/随身终端上下文

- 启用、常驻（蓝灯）、插入位置 @D 系统深度（after_char + extensions.position=4, depth=0）
- 作用：把终端传讯记录摘要注入主叙事，让AI知道手机里聊过什么
- 依赖：EJS（ST-Prompt-Template）、MVU 的 `getvar`

```
<手机互动摘要>
<%_
const phoneTermData = getvar('手机终端') ?? {};
const phoneTermConvs = phoneTermData['会话'] ?? {};
const phoneTermLines = [];
Object.keys(phoneTermConvs).forEach(function(name) {
  const msgs = (phoneTermConvs[name] ?? []).slice(-8);
  if (msgs.length > 0) {
    phoneTermLines.push('【与' + name + '的传讯】' + msgs.map(function(m) { return (m['r'] === 'u' ? '鲁迪乌斯' : name) + '：' + String(m['t'] ?? ''); }).join(' / '));
  }
});
const phoneTermText = phoneTermLines.join('\n');
_%>
<%_ if (phoneTermText) { _%>
以下是随身魔导终端中已发生、鲁迪乌斯当前知晓的传讯记录。可在剧情中自然承接已发生的约定与话题，但不要机械复述摘要：
<%- phoneTermText %>
使用边界：
- 传讯内容只对参与传讯的人物可知，未参与的人物不知道。
- 传讯互动不改变亲密度与关系阶段；关系变化仍按正文与既有变量规则推进。
- 不得因传讯内容跳过当前章节节点或推进主线。
<%_ } _%>
</手机互动摘要>
```

## 条目 2：变量更新规则补充（追加到既有 [mvu_update] 变量更新规则末尾）

```
# 随身终端（界面脚本）
- 消息楼层变量「手机终端」由随身终端脚本独自写入与维护；禁止在 <UpdateVariable> 中读取、更新或删除「手机终端」的任何字段。
- 传讯互动不改变亲密度与关系阶段；关系变化仍按既有规则在正文中推进。
```

## 变量契约

- `手机终端.会话.<角色名> = [{r:'u'|'c', t:'正文', ts:时间戳}]`，消息楼层变量顶层，**唯一写入者是终端脚本**，AI 不碰
- 只读展示：`stat_data` 的 关系/背包/日记/课题/世界/剧情/鲁迪/自由探索
